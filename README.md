# Piyush Rawat — Cybersecurity Portfolio

## Files
- `index.html` — website content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and back-to-top interaction
- `assets/portfolio-qr.png` — supplied portfolio QR code

## Preview locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder, preserving this structure.
3. Open repository Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/(root)`, then Save.

Your site will appear at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before publishing
Replace the GitHub placeholder with your real GitHub profile URL when available.
The supplied QR code is included as provided and links to `https://bit.ly/4zEa0TC?r=qr`.
